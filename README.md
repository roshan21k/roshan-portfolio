# Roshan K — Portfolio

A responsive academic and professional portfolio for Roshan K, M.Tech Data Science at IIT Palakkad.

## Content

- Academic background, education, technical skills, and certifications
- PercepNetLite: ongoing low-complexity speech enhancement work
- Grocery Store Web Application: full-stack development project
- Email, LinkedIn, and GitHub contact links

The site uses plain HTML and CSS, with no build step or external runtime dependencies.

## Preview

Open `index.html` in a browser, or serve this directory with a local HTTP server.

## Publish on GitHub Pages

1. Create a new public repository named `roshan-portfolio` under `roshan21k`.
2. Upload this folder's contents to the root of its `main` branch. Include `grocery-store.png` alongside `index.html` and `styles.css`.
3. In the repository, open **Settings → Pages**.
4. Set **Source** to **Deploy from a branch**, select **main** and **/ (root)**, and save.
5. Wait for the Pages deployment to complete.

The expected address after successful deployment is `https://roshan21k.github.io/roshan-portfolio/`.
This is a separate repository from the existing `portfolio` and `portfolio_` repositories.

## Editing

Update biography, education, projects, grades, and contact links in `index.html`. Update presentation and mobile layouts in `styles.css`. The speech project is described as ongoing; update that status when appropriate. The project screenshot comes from the existing public portfolio.

Use relative paths for local assets so the site works under the GitHub Pages repository path.
